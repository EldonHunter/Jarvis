📋 COMMANDES DISPONIBLES
🕐 HEURE & DATE
heure / date
Affiche l'heure et la date actuelles.
"Quelle heure est-il ?" · "Quel jour sommes-nous ?" · "Donne-moi la date"
📍 LOCALISATION
localisation
Affiche votre position sur une carte interactive.
"Où suis-je ?" · "Localise-moi" · "Affiche ma position" · "Montre la carte" · "Quelle est ma localisation ?"
🌤 MÉTÉO
météo
Affiche la météo en temps réel et les prévisions 5 jours.
"Quel temps fait-il ?" · "Quelle est la météo ?" · "Il fait combien dehors ?" · "Donne-moi les prévisions" · "Température actuelle"
🔢 CALCUL
calcul / nombre
Effectue un calcul mathématique.
"Calcule 42 fois 7" · "Combien font 150 plus 89 ?" · "Quel est le résultat de 512 divisé par 4 ?"
😄 BLAGUE
blague
A.R.C. raconte une blague.
"Raconte-moi une blague" · "Fais-moi rire" · "Tu connais une blague ?" · "Dis quelque chose de drôle"
💡 CITATION
citation
Partage une citation inspirante.
"Donne-moi une citation" · "Inspire-moi" · "Une pensée du jour" · "Dis-moi quelque chose de motivant"
🔄 CHANGER DE MODE
passage texte
Désactive le micro, affiche le champ de saisie.
"Passe en mode texte" · "Passage texte" · "Désactive le micro" · "Je veux écrire"
passage vocal
Réactive le micro et le mode vocal.
"Retour vocal" · "Passe en mode vocal" · "Réactive le micro" · "Mode vocal"
ℹ️ À PROPOS
aide / qui es-tu
Liste les fonctions ou présente A.R.C.
"Qu'est-ce que tu sais faire ?" · "Présente-toi" · "Aide-moi" · "Quelles sont tes capacités ?"
💬 QUESTIONS LIBRES
tout le reste
Toute question non reconnue est envoyée à l'intelligence centrale d'A.R.C. (IA générative).
Exemples : "Explique-moi le Big Bang", "Écris-moi un haïku", "Traduis bonjour en japonais"…
⚡ IDÉES D'AUTOMATISMES
🔊 CONTRÔLE DU VOLUME
Augmenter, diminuer ou couper le son du navigateur. "Monte le volume", "Coupe le son", "Volume à 50%".
POSSIBLE via Web Audio API
🌙 MODE SOMBRE / CLAIR
Basculer le thème de l'interface entre sombre et lumineux. "Active le mode clair", "Passe en mode sombre".
POSSIBLE nativement
🔕 NE PAS DÉRANGER
Suspendre toutes les notifications et écoute vocale pour une durée définie. "Ne me dérange pas pendant 30 minutes".
POSSIBLE nativement
⏱ MINUTEUR / ALARME
Lancer un compte à rebours ou une alarme vocale. "Minuteur 5 minutes", "Rappelle-moi dans 1 heure".
POSSIBLE nativement
📋 COPIER DANS LE PRESSE-PAPIER
Copier automatiquement la dernière réponse d'A.R.C. "Copie la réponse", "Copie ce texte".
POSSIBLE via Clipboard API
🖥 PLEIN ÉCRAN
Passer l'interface en plein écran ou quitter. "Plein écran", "Quitte le plein écran".
POSSIBLE via Fullscreen API
🔗 OUVRIR UN SITE WEB
Ouvrir un lien dans un nouvel onglet. "Ouvre YouTube", "Va sur Google", "Ouvre Wikipedia".
POSSIBLE via window.open
❌ FERMER L'ONGLET ACTUEL
Fermer l'onglet en cours. "Ferme cet onglet", "Quitte". Fonctionne si l'onglet a été ouvert par un script.
PARTIEL (selon origine)
📸 CAPTURE D'ÉCRAN
Capturer l'écran et télécharger l'image. "Prends une capture", "Screenshot".
PARTIEL via html2canvas
📁 TÉLÉCHARGER UN FICHIER
Générer et télécharger un fichier (résumé, rapport, texte). "Télécharge la conversation", "Exporte le log".
POSSIBLE nativement
💡 RAPPORT MÉTÉO AUTOMATIQUE
Afficher automatiquement la météo au démarrage ou toutes les X heures sans demande.
POSSIBLE nativement
🎵 LECTURE MUSICALE
Lire une playlist locale ou ouvrir Spotify/YouTube Music. "Mets de la musique", "Lance Spotify".
LIMITÉ (ouverture d'onglet)
🔔 NOTIFICATIONS BUREAU
Envoyer des notifications système même si l'onglet est en arrière-plan. "Notifie-moi quand…"
POSSIBLE via Notifications API
📡 PING RÉSEAU
Vérifier la connexion internet et la latence. "Teste ma connexion", "Suis-je connecté ?".
POSSIBLE nativement
